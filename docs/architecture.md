# Архитектура

## Сборка

Ни Gradle, ни runtime-библиотек. `build.sh` запускает `aapt2` (ресурсы и ассеты) → `javac
--release 11` против `android.jar` (API 34) → `d8` (min API 24) → `zipalign` → `apksigner`
(локальный debug-ключ или приватный релизный ключ через `RELEASE_KEYSTORE`). В Windows то же
делает `build.ps1`.

Шрифты (Inter, OFL) и веб-приложение презентации — обычные ассеты; генератор QR-кодов —
вендоренный исходник (Nayuki, MIT) в `src/io/nayuki/qrcodegen`.

| `Suggestions.java` | Рекомендации JustWatch / TMDB / Stremio (Cinemeta): загрузка, кэш, изображения, deep links |

| `Weather.java` | Прогноз из Open-Meteo, MET Norway или wttr.in (с резервом) в едином формате, определение по IP / поиск города, кэш, расписание обновлений |

## Проектные решения

- **Сначала измерить Apple.** Геометрия взята с пресс-скриншота Apple tvOS 26, приведённого к
  1920×1080 (док в 48 px от краёв, карточки 248×148 px, промежутки 51 px, верх дока на 73 %,
  фокус 1,2×), и из HIG (безопасная зона 60/80 pt, иконки 800×480, состояния фокуса и нажатия).
- **Liquid Glass без API размытия фона.** Лаунчер знает, что находится за его стеклом (свои обои
  или изображение карусели), поэтому один раз для каждого фона запекает уменьшенную размытую
  копию с усиленной насыщенностью, а GPU рисует стекло как залитые шейдером скруглённые
  прямоугольники, выровненные по положению поверхности на экране, плюс увеличенные краевые полосы
  (линзы) и градиентную зеркальную кайму.
- **Рекомендации без системного доступа.** Строки preview/Watch Next в Android требуют
  разрешения с системной подписью (проверено: читается 0 строк), поэтому верхняя полка
  использует JustWatch/TMDB, а «Продолжить просмотр» — опубликованные медиасессии.

- **Поиск без списка сервисов.** JustWatch сообщает, какие сервисы в Индии имеют название, и
  даёт ссылки каждого из них; tvOS Launcher сам находит приложение для каждого сервиса (пакет в
  Android TV-ссылке, установленный обработчик веб-ссылки, не являющийся браузером, запомненное
  соответствие или установленное приложение с тем же именем), поэтому новые сервисы не требуют
  обновления. Android 11+ скрывает другие приложения без объявления, поэтому `<queries>` в
  манифесте перечисляет лаунчеры, голосовой ввод, службу распознавания речи и обработчики https.
- **Поиск остаётся лёгким.** Это оверлей в `MainActivity` (без новой активности): приложения
  сопоставляются по списку, уже находящемуся в памяти, на каждое нажатие клавиши; названия
  загружаются через 350 мс после паузы ввода с отменой предыдущего запроса, последние 20 запросов
  кэшируются, постеры декодируются в размере карточки в LRU с ограничением кучи, а пока поиск
  открыт, слои главного экрана под ним не рисуются и карусель ставится на паузу. Ввод измерен:
  p50 6 мс / p90 11 мс на кадр на телевизоре Android 9 с 1 ГБ ОЗУ.
- **Диктовка.** `SpeechRecognizer` (голосовая служба Google для ТВ) с частичными результатами
  заполняет поле в реальном времени после системного запроса микрофона; иначе `RecognizerIntent`
  открывает голосовой запрос телевизора. Кнопку ассистента на пультах Android направляет в Google
  Assistant раньше приложений, поэтому ярлык на пульте — удержание «Назад» на 1 с («Назад»
  воспроизводится, если отпустить раньше).

## Производительность (Mi Box, Mali-450 MP, GLES 2.0)

- Запуск: список приложений (менеджер пакетов, баннеры, цвета иконок) и обои готовятся в фоновых
  потоках, пока строятся представления окна: холодный старт ~1,0 с → ~0,86 с на телевизоре
  Android 9 с 1 ГГц.

- Никаких постоянных анимаций (нет дрейфа обоев, нет покачивания при бездействии): в простое
  рисуется 0 кадров.
- Во время переходов в UI-потоке ничего не рисуется программно (исходный кэш стекла вызывал
  замирания ~1 с при переходе в док и из него).
- Градиенты читаемости запекаются в обои и изображения; фон окна убран, чтобы избежать скрытых
  полноэкранных заливок.
- Измеряйте через `adb shell dumpsys gfxinfo com.techgenius.tvoslauncher` — навигация по доку идёт
  с медианой 16 мс; полноэкранные переходы ограничены скоростью заливки GPU (~30 fps на этой
  приставке).
