# Перевод на русский

Этот форк — русская версия **[tvOS Launcher](https://github.com/techgenius1/tvOS-Launcher)**
(версия **2.2.5**, versionCode 17, коммит апстрима
`b14942965c240b78030e83461550cb23509163a1`). Переведён весь интерфейс лаунчера и вся
документация; код, структура проекта и лицензия остались такими же, как в оригинале.

## Что переведено

| Область | Состояние |
|---|---|
| Строки интерфейса (`I18n.java`, словарь `initRussian()`) | 928 записей `ru(english, russian)` |
| Исходные английские строки из `values/strings.xml` | 369 записей `add(...)`, все с русским переводом |
| Динамические строки (счётчики, даты, время, склонения) | 102 правила `buildRuRules()` |
| `res/values-ru/strings.xml` | Названия служб и описание разрешения |
| Экран первичной настройки, все страницы настроек, диалоги, тосты | полностью |
| Панель управления, поиск, карусель, профили, входы, презентация | полностью |
| `README.md`, `CONTRIBUTING.md`, `docs/*.md` | полностью на русском |

## Как это устроено

Оригинальный лаунчер хранит переводы прямо в `I18n.java`: словарь с ключом по английской строке
и функция `ru(...)`, которая регистрирует пару «английский → русский». Русский словарь добавлен
отдельным блоком рядом с другими языками, чтобы обновления из апстрима было проще переносить:

```java
private static void initRussian() {
    ru("Home", "Главная");
    ru("Control Panel", "Панель управления");
    ...
}
```

Порядок вызовов: `initEnglish() → initTurkish() → ... → initPolish() → initRussian()`.

Строки, собранные из частей, переводятся не словарём, а правилами: `buildRuRules()` содержит
регулярные выражения с плейсхолдерами (`{1}`, `{t1}`, `{p1:one|few|many}`, `{k:Key}`), которые
собирают русское предложение из английского шаблона и аргументов.

Счётчики «число + единица» (ряды, часы, минуты, приложения, слайды и т. п.) идут через
`I18n.count(context, n, ...)`, который использует русские правила склонения (`ruPlural`): 1 ряд,
2 ряда, 5 рядов, 11 рядов, 21 ряд, 22 ряда.

## Что оставлено без перевода

Названия технологий, функций и продуктов не переводятся — так же, как в остальных локализациях
оригинала:

`tvOS`, `tvOS Launcher`, `Android TV`, `Google TV`, `Wi-Fi`, `Bluetooth`, `ADB`, `HDMI`, `USB`,
`APK`, `TMDB`, `JustWatch`, `Stremio`, `Nuvio`, `Lampa`, `YouTube`, `SmartTube`, `Netflix`,
`Disney+`, `HBO Max`, `TCL`, `Philips`, `Xiaomi`, `Sony`, `Mi Box`, `CleanYourTV`, `ScanCode`,
`D-Pad`, `Ambient Mode`, `Aerial Views`, `AirPlay`, `Mac`, `iPhone`, `iPad`, `Linux`, `Windows`,
`macOS`, а также имена команд, пакетов (`com.techgenius.tvoslauncher`), ключи и параметры
командной строки.

Термины Apple, которые используются как названия функций интерфейса, тоже сохранены:
`Liquid Glass`, `Night Scenes` переводится как «ночные сцены», но название режима в интерфейсе
остаётся узнаваемым.

## Как включить русский язык

1. На телевизоре: **Настройки лаунчера → Язык → Русский**.
2. Если системный язык Android TV — русский и настройки лаунчера ещё не сохранены (или данные
   приложения сброшены), язык выбирается автоматически при первом запуске.

## Сборка русской сборки

Сборка не отличается от оригинальной:

```sh
./build.sh                                    # macOS / Linux → build/tvos-home.apk
powershell -ExecutionPolicy Bypass -File .\build.ps1   # Windows → build\tvos-home.apk
```

Русские строки лежат в исходниках, отдельных флагов сборки не нужно.

## Обновления

Автоматические обновления (`AppUpdater`) в этой сборке проверяют релизы **этого** репозитория:
`https://api.github.com/repos/disasdter/tvOS-Launcher-RUS-/releases/latest`. Оригинальный проект
используется только как источник кода, его релизы сюда не устанавливаются.

Чтобы выпустить обновление:

1. Соберите APK (`build.ps1` / `build.sh`).
2. Создайте релиз с тегом вида `v2.2.5` в этом репозитории.
3. Приложите файл `tvos-home.apk` к релизу — по этому имени лаунчер находит APK для скачивания.

## Подпись и установка

Русская сборка подписана локальным debug-ключом (`CN=tvOS Launcher debug`), поэтому она не
встаёт поверх официальной сборки. Порядок:

```sh
adb uninstall com.techgenius.tvoslauncher      # настройки сбросятся — сделайте бэкап
adb install -r build/tvos-home.apk
```

Восстановить настройки можно из файла, созданного через **Настройки → Система → Резервная
копия** (`Download/tvos-launcher-settings.json`).

## Синхронизация с апстримом

```sh
git remote add upstream https://github.com/techgenius1/tvOS-Launcher.git
git fetch upstream
git merge upstream/main
```

При конфликтах в `I18n.java` русский блок `initRussian()` и правила `buildRuRules()` обычно можно
оставить как есть: новые английские строки просто появятся в интерфейсе на английском, пока их не
добавят в словарь. Это безопасно — остальной перевод продолжит работать.
